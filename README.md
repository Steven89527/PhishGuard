# PhishGuard

PhishGuard is a browser-based educational phishing simulation designed to help users recognize common phishing warning signs.

## Features
-8 fictional legitimate and phishing email scenarios
Instant feedback after each answer
Explanation of the warnings signs
Score and percentage tracking
Streak tracking
Final results screen 
Mobile-friendly design

## How to Run

Download or clone this repository.
Open "index.html" in a web browser.
Click "Start Training" to begin the simulator.

##How to Edit

### Email Scenarios

Open "script.js" and find the "scenarios" section. Each scenario contains:
Sender
Subject
Email message
Whether it's legitimate or phishing 
Explanation

### Website Design
Open "style.css" to change colors, fonts, spacing, buttons, and other visual elements.

### Website Content
Open "index.html" to edit the text and structure of the website.
